# Syed Shahkar Bukhari — Portfolio

Animated one-page portfolio. IT Cell Manager at the Directorate General of Land Use & Building Control Authority (LUBCA), Khyber Pakhtunkhwa.

## Publish on GitHub Pages
1. Upload all files in this folder to a repository (keep `index.html` at the top level).
2. Go to **Settings → Pages**, set Source to **Deploy from a branch**, branch **main**, folder **/ (root)**, then Save.
3. After a minute the site is live at `https://<your-username>.github.io/<repo-name>/`.

Tip: name the repository `<your-username>.github.io` to get the shorter address `https://<your-username>.github.io/`.

## Files
- `index.html` — page content
- `assets/css/style.css` — design and animations
- `assets/js/main.js` — typing effect, scroll animations, theme switch
- `assets/images/profile.jpg` — profile photo (replace with same name to change it)
